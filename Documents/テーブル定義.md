# テーブル定義 - MailCare

MailCare は 2 種類の SQLite データベースを使います。

| 種類 | ファイル | スキーマ管理 | 内容 |
| --- | --- | --- | --- |
| マスター DB | `data/mailcare.db` | `app/migrations/0001_init.sql`（goose） | 利用者、トークン、設定、メールアドレス、ジョブ |
| 索引 DB | `data/mails/<address>.sqlite`（メールアドレスごとに 1 ファイル） | `app/models/mailindex.go`（`PRAGMA user_version`） | 取り込んだメール、纏めグループ、分析報告 |

日時列はすべて UTC で保存します（表示時に利用者のタイムゾーンへ変換します）。JSON 列は列名を `*_info` とし、型欄に `TEXT (JSON)` と記載して各表の直後にレイアウトを記載します。テーブルを追加・変更した場合は本書を更新してください。

```text
マスター DB                          索引 DB（アドレスごと）
users   tokens   settings            messages  *---0..1 groups 1---* agent_reports
mailboxes 1---* jobs                 （messages.detail_info にバウンス抽出結果を内包）
```

## 1. マスター DB（`data/mailcare.db`）

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー | |
| username | TEXT | NO | - | 一意、1〜64 文字 | ユーザー名（`[A-Za-z0-9_.-]`） |
| display_name | TEXT | NO | - | 1〜128 文字 | 表示名 |
| email | TEXT | NO | `''` | 254 文字以内 | 通知用メールアドレス（任意。空なら通知先にならない） |
| language | TEXT | NO | `'ja'` | `ja` / `en` | 画面の言語 |
| timezone | TEXT | NO | `'Asia/Tokyo'` | 1〜64 文字 | 表示用タイムゾーン（IANA 名。UTC で保存した日時をこの利用者向けに変換する） |
| theme | TEXT | NO | `'auto'` | `auto` / `light` / `dark` | 画面のテーマ（`auto` はブラウザの設定に従う） |
| password_hash | TEXT | NO | - | | bcrypt ハッシュ（コスト 12） |
| role | TEXT | NO | `'user'` | `admin` / `user` | 役割（`user` は閲覧のみ） |
| created_at | DATETIME | NO | datetime('now') | | 作成日時 |
| updated_at | DATETIME | NO | datetime('now') | | 更新日時 |
| last_login_at | DATETIME | YES | NULL | | 最終ログイン日時 |

リレーション: なし。

| value | TEXT | NO | - | | 設定値（文字列として保存） |

リレーション: なし。

| key | 説明 | 既定値 |

### mailboxes

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー | |

| display_name | TEXT | NO | `''` | 128 文字以内 | 表示名 |
| enabled | INTEGER | NO | 1 | 0 / 1 | 有効なら 1（無効なアドレスは自動同期の対象外） |
| detail_info | TEXT (JSON) | NO | - | `json_valid` | メールサーバー接続設定（JSON レイアウトは下記。`protocol` で種類を示す） |
| last_fetched_at | DATETIME | YES | NULL | | 最終受信日時（未実行なら NULL） |
| last_fetch_error | TEXT | NO | `''` | 2000 文字以内 | 最終受信のエラー内容（空なら成功） |
| created_at | DATETIME | NO | datetime('now') | | 作成日時 |
| updated_at | DATETIME | NO | datetime('now') | | 更新日時 |

#### `mailboxes.detail_info` の JSON レイアウト

| キー | 型 | 説明 |
| --- | --- | --- |
| protocol | string | 受信プロトコル（現在は `imap` のみ。将来 `pop3` などを追加できる） |
| host | string | IMAP サーバーのホスト名（同じホストのアドレスは順番に処理される） |
| port | number | IMAP ポート（既定 993） |
| security | string | 接続方式（`ssl` = IMAPS / `starttls` / `none`） |
| username | string | IMAP ユーザー名 |
| password_enc | string | IMAP パスワード（`data/mailcare.key` で AES-256-GCM 暗号化） |
| folder | string | 監視するフォルダー（既定 `INBOX`） |
| initial_days | number | 初回受信で遡る日数（既定 90） |
| recent_days | number | 2 回目以降の受信で遡る日数（既定 30） |

リレーション: `jobs.mailbox_id` から参照される（1 対多）。索引 DB `data/mails/<address>.sqlite` と 1 対 1 に対応する。

### jobs

バックグラウンド処理（ジョブ）。

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー | |
| kind | TEXT | NO | - | `sync` / `fetch` / `group` / `analyze` / `reindex` / `reclassify` / `notify` | 種別 |
| mailbox_id | INTEGER | YES | NULL | `mailboxes.id`（削除時 NULL） | 対象メールアドレス。NULL は「全アドレスに展開する」ジョブ（`notify` は常に NULL） |
| target | TEXT | NO | `''` | 320 文字以内 | 追加の対象（`analyze`: グループキー / `*` = 対応対象の全グループ / 空 = 解析待ち。`notify`: 空 = 通知先へ送信 / `test:<address>` = テスト送信） |
| status | TEXT | NO | `'queued'` | `queued` / `running` / `done` / `error` / `canceled` | 状態 |
| requested_by | TEXT | NO | `''` | 80 文字以内 | 投入元（`scheduler` / `cli` / `web:<username>`） |
| detail_info | TEXT (JSON) | NO | `'{}'` | `json_valid` | 実行結果（JSON レイアウトは下記） |
| created_at | DATETIME | NO | datetime('now') | | 投入日時 |
| started_at | DATETIME | YES | NULL | | 開始日時 |
| finished_at | DATETIME | YES | NULL | | 終了日時 |

リレーション: `mailbox_id` → `mailboxes.id`（多対 1）。索引: `idx_jobs_status_created (status, created_at)`。

#### `jobs.detail_info` の JSON レイアウト

| キー | 型 | 説明 |
| --- | --- | --- |
| progress | string | 進捗テキスト（実行中に随時更新、最新 200 行） |
| result | string | 結果の要約 |
| error | string | エラー内容（成功時は無し） |

## 2. 索引 DB（`data/mails/<address>.sqlite`）

スキーマ版: `PRAGMA user_version = 3`。

### messages

取り込んだメール（バウンス以外も含む全件）。原文は同じディレクトリの `<message_key>.eml` / `.txt` / `.html` / `.json`。

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー | |
| message_key | TEXT | NO | - | 一意、1〜64 文字 | メールキー（`YYYYMMDD-HHMMSS_<12桁hex>`）。ファイル名の基底 |
| folder | TEXT | NO | `'INBOX'` | 1〜255 文字 | 取得元フォルダー |
| uidvalidity | INTEGER | NO | - | | 取得時のフォルダーの UIDVALIDITY |
| uid | INTEGER | NO | - | | IMAP UID |
| message_id | TEXT | NO | `''` | 998 文字以内 | Message-ID ヘッダー（UIDVALIDITY 変更後の重複判定に使う） |
| subject | TEXT | NO | `''` | 2000 文字以内 | 件名（MIME デコード済み。検索対象） |
| from_address | TEXT | NO | `''` | 320 文字以内 | 差出人アドレス（検索対象） |
| from_name | TEXT | NO | `''` | 500 文字以内 | 差出人表示名（検索対象） |
| to_address | TEXT | NO | `''` | 320 文字以内 | 宛先アドレス（先頭。検索対象） |
| to_name | TEXT | NO | `''` | 500 文字以内 | 宛先表示名（先頭） |
| date | DATETIME | NO | - | | メール日時（Date ヘッダー、無ければ INTERNALDATE、無ければ取得時刻。並び替えに使う） |
| received_at | DATETIME | YES | NULL | | IMAP INTERNALDATE |
| size | INTEGER | NO | 0 | 0 以上 | サイズ（バイト） |
| has_text | INTEGER | NO | 0 | 0 / 1 | text/plain パートに空白以外の本文があれば 1 |
| has_html | INTEGER | NO | 0 | 0 / 1 | text/html パートに空白以外の本文があれば 1 |
| body_source | TEXT | NO | `''` | `text` / `html` / 空 | 判定・抽出に使った本文（両方に有効な本文があれば `text`、text が空なら HTML をテキスト化した `html`、どちらも無ければ空） |
| is_bounce | INTEGER | NO | 0 | 0 / 1 | 対象判定でバウンス（自動返信を含む）と判定されれば 1 |
| bounce_kind | TEXT | NO | `''` | `failed` / `delayed` / `auto_reply` / `other` / 空 | メールデーモン通知の種別（配信不能 / 遅延 / 自動返信 / その他。対象外は空。自動返信はグループに入れない） |
| classified | INTEGER | NO | 0 | 0 / 1 | 纏めフェーズで処理済みなら 1（受信直後は 0） |
| group_key | TEXT | NO | `''` | 16 文字以内 | 所属する纏めグループ（`groups.group_key`。対象外・自動返信は空） |
| detail_info | TEXT (JSON) | NO | `'{}'` | `json_valid` | バウンス抽出結果と判定ルール名（JSON レイアウトは下記。バウンスでなければ `rule` のみ） |
| fetched_at | DATETIME | NO | - | | 取り込み日時 |

制約: `UNIQUE(folder, uidvalidity, uid)`。索引: `idx_messages_date (date)`、`idx_messages_message_id (message_id)`、`idx_messages_bounce (is_bounce, date)`、`idx_messages_classified (classified)`、`idx_messages_group (group_key)`。
リレーション: `group_key` → `groups.group_key`（多対 1、外部キー制約なし）。

#### `messages.detail_info` の JSON レイアウト

| キー | 型 | 説明 |
| --- | --- | --- |
| rule | string | 対象判定で一致したルール名（`dsn_report` / `daemon_sender` / `subject_pattern` / `auto_reply` / `daemon_display_name`。判定ルールの調整に使う。対象外メールにも残る） |
| recipient | string | 配信できなかった宛先アドレス |
| recipient_domain | string | 宛先ドメイン |
| action | string | DSN の Action（`failed` / `delayed` / `delivered` / `relayed` / `expanded`） |
| status_code | string | 拡張状態コード（例 `5.1.1`） |
| smtp_code | string | SMTP 応答コード（例 `550`。通知に実値が無ければ空） |
| diagnostic | string | 診断文（Diagnostic-Code または本文から抽出、4000 文字以内） |
| diagnostic_template | string | 診断テンプレート（揺れを除いた正規化文字列、300 文字以内） |
| remote_mta | string | 相手側 MTA のホスト名 |
| remote_ip | string | 相手側 MTA の IP アドレス |
| reporting_mta | string | 通知を作成した MTA（当方側） |
| responsible | string | 対応者区分（`sender` / `recipient` / `domain` / `unknown`。所属グループと同じ値） |
| original_message_id | string | 元メールの Message-ID |
| original_from | string | 元メールの差出人 |
| original_subject | string | 元メールの件名 |
| original_date | string (RFC 3339) | 元メールの日時 |

### groups

バウンスを対応基準単位で束ねた纏めグループ。

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| group_key | TEXT | NO | - | 主キー、16 文字 | `sha1(category|unit_value|authority)` の先頭 16 桁 |
| category | TEXT | NO | - | 13 値の列挙 | 対応対象: `ip_blocked` / `rate_limited` / `auth_failure` / `sender_blocked` / `content_rejected` / `message_too_large` / `server_config` / `unknown_failure`。対象外: `user_unknown` / `mailbox_full` / `mailbox_disabled` / `domain_not_found` / `delivery_delay` |
| actionable | INTEGER | NO | 1 | 0 / 1 | メールサーバー管理者が対応すべきなら 1。宛先側の問題は 0（アラートから除外、解析もしない） |
| unit_value | TEXT | NO | `''` | 320 文字以内 | 対応単位（送信 IP、送信元アドレス、送信ドメイン、当方 MTA。対象外では宛先アドレス・宛先ドメイン。検索対象） |
| authority | TEXT | NO | `''` | 320 文字以内 | 判断主体（ブラックリスト提供元、宛先ドメイン。`unknown_failure` では状態コードと診断テンプレート。検索対象） |
| recipient_domain | TEXT | NO | `''` | 253 文字以内 | 代表の宛先ドメイン（検索対象） |
| status_code | TEXT | NO | `''` | 11 文字以内 | 代表の拡張状態コード |
| diagnostic_template | TEXT | NO | `''` | 300 文字以内 | 代表の診断テンプレート（検索対象） |
| responsible | TEXT | NO | `''` | `sender` / `recipient` / `domain` / `unknown` / 空 | 対応者区分（カテゴリ由来。解析報告の META が確定値を返せば上書き。絞り込みに使う） |
| state | TEXT | NO | `'open'` | `open` / `resolved` / `ignored` | 対応状態（絞り込みに使う） |
| state_updated_at | DATETIME | YES | NULL | | 状態の変更日時 |
| needs_analysis | INTEGER | NO | 1 | 0 / 1 | 解析が必要（新規、メールが増えた、前回の解析が失敗）なら 1。解析完了で 0 |
| message_count | INTEGER | NO | 0 | 0 以上 | 所属メール数 |
| recipient_count | INTEGER | NO | 0 | 0 以上 | 宛先アドレスの種類数 |
| remote_ip_count | INTEGER | NO | 0 | 0 以上 | 相手側 IP の種類数 |
| first_seen | DATETIME | YES | NULL | | 最古のメール日時 |
| last_seen | DATETIME | YES | NULL | | 最新のメール日時（並び替えに使う） |
| created_at | DATETIME | NO | - | | 作成日時 |
| updated_at | DATETIME | NO | - | | 更新日時 |

索引: `idx_groups_state (actionable, state, last_seen)`。
リレーション: `messages.group_key` から参照される（1 対多）。`agent_reports.group_key` から参照される（1 対多）。
