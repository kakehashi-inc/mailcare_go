# テーブル定義 - MailCare

MailCare は 2 種類の SQLite データベースを使います。

| 種類 | ファイル | 内容 |
| --- | --- | --- |
| マスター DB | `data/mailcare.db` | 利用者、トークン、設定、メールアドレス、ジョブ |
| 索引 DB | `data/mails/<address>.sqlite`（メールアドレスごとに 1 ファイル） | 取り込んだメール、纏めグループ、分析報告 |

日時列はすべて UTC で保存します。既定値を持つ列はありません（既定値欄の `-` は既定値なし）。長さを断定できる文字列の列は `VARCHAR(n)` で長さを宣言し、断定できないものは `TEXT` とし、CHECK 制約は使いません（列挙値は各列の「値」に記載します）。JSON 列は列名を `*_info` とし、型欄に `TEXT (JSON)` と記載して各表の直後にレイアウトを記載します（`mailboxes.detail_info` の 1 列だけで、他のテーブルに JSON 列はありません）。テーブルを追加・変更した場合は本書を更新してください。値の扱い（いつ・どう書き込むか、画面や処理での使われ方）は [システム仕様.md](システム仕様.md) に記載します。

どちらの DB もマイグレーションツール goose で管理します（マスター DB は `app/migrations/master/`、索引 DB は `app/migrations/index/`）。各 DB には goose が自身の適用履歴のために作る管理表 `goose_db_version` があります（goose が作成・更新するもので、本書の既定値の規則の対象外です）。索引 DB の表に後から NOT NULL の列を足すマイグレーションでは、既存の行のために既定値を持たせることがあります（SQLite の制約による例外。その列は本書の既定値欄に記載します）。

```text
マスター DB                          索引 DB（アドレスごと）
users   tokens   settings            messages 1---0..1 bounces *---0..1 groups 1---* agent_reports 1---* agent_report_patterns
mailboxes 1---* jobs
```

### dmarc_records

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |  |
| message_id | INTEGER | NO | - | `messages.id`（メール削除時にカスケード削除） | レポートのメール |
| group_key | VARCHAR(16) | NO | - | | 所属する纏めグループ（`groups.group_key`） |
| category_rule | VARCHAR(64) | NO | - | | カテゴリ判定で一致した規則の名前。値: `dmarc_spf_missing` / `dmarc_dkim_failed` / `dmarc_strict_alignment` / `dmarc_not_authorized` / `dmarc_unaligned` |
| diagnostic_template | TEXT | NO | - | | 記録の形（記録のドメイン（`header_from`）と揃った DKIM・SPF の結果と処置。例 `dmarc fail: dkim none; spf aligned none; disposition reject`） |
| pattern_key | VARCHAR(16) | NO | - | | グループ内のパターン（`sha1(\|diagnostic_template\|\|dmarc)` の先頭 16 桁） |
| report_org | TEXT | NO | - | | 報告元（`report_metadata/org_name`） |
| report_id | TEXT | NO | - | | レポート ID |
| begin_at | DATETIME | YES | - | | 集計期間の開始 |
| end_at | DATETIME | YES | - | | 集計期間の終了 |
| policy_domain | TEXT | NO | - | | 公開ポリシーのドメイン（`policy_published/domain`） |
| policy | VARCHAR(32) | NO | - | | 公開ポリシー（`p=`）。値: `none` / `quarantine` / `reject` / 空 |
| header_from | TEXT | NO | - | | From ヘッダーのドメイン |
| envelope_from | TEXT | NO | - | | エンベロープ送信者のドメイン（無ければ空） |
| source_ip | VARCHAR(45) | NO | - | | 送信元 IP |

| spf_auth | TEXT | NO | - | | SPF の検証結果の一覧（`ドメイン 結果, ...`。無ければ `none`） |

索引: `idx_dmarc_records_message (message_id)`、`idx_dmarc_records_group (group_key, pattern_key)`。

### groups

| unit_value | TEXT | NO | - | | 対応単位（送信 IP、送信元アドレス、送信ドメイン、当方 MTA、宛先アドレス、宛先ドメイン、DMARC の記録のドメインなど） |
| authority | TEXT | NO | - | | 判断主体（ブラックリスト提供元、宛先ドメインなど） |

| diagnostic_template | TEXT | NO | - | | 代表の診断テンプレート |

| state | VARCHAR(32) | NO | - | | 対応状態。値: `open` / `resolved` / `ignored` |
| state_updated_at | DATETIME | YES | - | | 状態の変更日時 |
| needs_analysis | INTEGER | NO | - | | 解析待ちなら 1。値: 0 / 1 |
| message_count | INTEGER | NO | - | | 所属メール数（複数の記録が同じグループに属するレポートは 1 通と数える） |
| recipient_count | INTEGER | NO | - | | 宛先アドレスの種類数（バウンスのみ） |
| remote_ip_count | INTEGER | NO | - | | 相手側 IP（バウンス）と送信元 IP（DMARC の記録）の種類数 |
| first_seen | DATETIME | YES | - | | 最古のメール日時 |
| last_seen | DATETIME | YES | - | | 最新のメール日時 |
| created_at | DATETIME | NO | - | | 作成日時 |

索引: `idx_groups_state (actionable, state, last_seen)`。
リレーション: `bounces.group_key`・`dmarc_records.group_key` から参照される（1 対多）。`agent_reports.group_key` から参照される（1 対多）。

### agent_reports

エージェント CLI による解析報告（グループごとの履歴）。

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |  |
| group_key | VARCHAR(16) | NO | - | `groups.group_key`（グループ削除時にカスケード削除） | 対象グループ |
| provider | VARCHAR(64) | NO | - | | 使用したプロバイダー（`codex` 等） |
| status | VARCHAR(32) | NO | - | | 状態。値: `running` / `completed` / `error` |
| severity | VARCHAR(32) | NO | - | | 重大度。値: `high` / `medium` / `low` / 空 |
| responsible | VARCHAR(32) | NO | - | | エージェントが判断した対応者区分。値: `sender` / `recipient` / `domain` / `unknown` / 空 |
| summary | TEXT | NO | - | | 要約 |
| report_markdown | TEXT | NO | - | | 報告本文（Markdown） |
| error_message | TEXT | NO | - | | 失敗理由（成功時は空） |
| confidence | VARCHAR(16) | NO | - | | 原因の確度。値: `high` / `medium` / `low` / 空 |
| message_count | INTEGER | NO | - | | 解析時点のグループのメール数 |

### agent_report_patterns

解析が決着した報告が扱ったグループのパターン（`bounces.pattern_key` と `dmarc_records.pattern_key`）。

| カラム名 | 型 | NULL | 既定値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| report_id | INTEGER | NO | - | 主キー（`report_id`, `pattern_key`）、`agent_reports.id`（報告削除時にカスケード削除） | 報告 |
| pattern_key | VARCHAR(16) | NO | - | 主キー（同上） | 報告が扱ったパターン |

リレーション: `report_id` → `agent_reports.id`（多対 1）。`pattern_key` は `bounces.pattern_key` または `dmarc_records.pattern_key` と同じ値（外部キー制約なし）。
