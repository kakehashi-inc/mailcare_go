# テーブル定義 - システム名をここに記載

データベースは SQLite（データディレクトリ内の `develop_app.db`）です。スキーマは `app/migrations` の goose マイグレーションで管理し、起動時に自動適用されます。テーブルを追加・変更した場合は本書を更新してください。

## tokens

API サーバーの Bearer 認証に使うアクセストークン。モデル: `app/models/token.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| identifier | TEXT | NO | - | 識別子（`[A-Za-z0-9_-]`、64 文字以内、一意） |
| name | TEXT | NO | - | 表示名 |
| token | TEXT | NO | - | トークン値（`dap_` + 40 桁の 16 進、一意） |
| is_default | INTEGER | NO | 0 | デフォルトトークンなら 1（常に 1 件のみ） |
| expires_at | DATETIME | YES | NULL | 有効期限（NULL は無期限） |
| created_at | DATETIME | NO | datetime('now') | 作成日時（UTC） |

リレーション: なし

## settings

サーバー設定のうち、コードの既定値と異なる値のみを保存するキー / バリューストア。モデル: `app/models/setting.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| key | TEXT | NO | - | 設定キー（主キー）。`app/modules/constants.go` の `Setting*` 定数 |
| value | TEXT | NO | - | 設定値（文字列として保存） |

リレーション: なし

現在使用しているキー:

| key | 説明 | 既定値 |
| --- | --- | --- |
| api_listen | API サーバーの待受アドレス | `0.0.0.0` |
| web_listen | Web サーバーの待受アドレス | `0.0.0.0` |
| api_port | API サーバーの待受ポート | `8081` |
| web_port | Web サーバーの待受ポート | `8080` |

## goose_db_version（goose 管理）

goose がマイグレーションの適用状況を記録するために自動作成するテーブル。アプリケーションからは参照・更新しません。
