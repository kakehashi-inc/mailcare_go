# テーブル定義 - MailCare

MailCare は 2 種類の SQLite データベースを使います。

| 種類 | ファイル | スキーマ管理 | 内容 |
| --- | --- | --- | --- |
| マスター DB | `data/mailcare.db` | `app/migrations` の goose マイグレーション（起動時に自動適用） | 利用者、ログイントークン、設定、メールアドレス、ジョブ |
| 索引 DB | `data/mails/<address>.sqlite`（メールアドレスごとに 1 ファイル） | `app/models/mailindex.go` の `PRAGMA user_version`（版が古ければ原文から自動再構築） | 取り込んだメール、バウンス抽出結果、纏めグループ、分析報告 |

索引 DB は原文ファイル（`data/mails/<address>/<message_key>.eml`）から再生成できる派生データです。テーブルを追加・変更した場合は本書を更新してください。

## 1. マスター DB（`data/mailcare.db`）

### users

Web 画面にログインする利用者。モデル: `app/models/user.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| username | TEXT | NO | - | ユーザー名（`[A-Za-z0-9_.-]`、64 文字以内、一意） |
| display_name | TEXT | NO | - | 表示名 |
| password_hash | TEXT | NO | - | bcrypt ハッシュ |
| role | TEXT | NO | `'user'` | 役割（`admin` / `user`） |
| created_at | DATETIME | NO | datetime('now') | 作成日時（UTC） |
| updated_at | DATETIME | NO | datetime('now') | 更新日時（UTC） |
| last_login_at | DATETIME | YES | NULL | 最終ログイン日時（UTC） |

リレーション: `tokens.user_id` から参照される（1 対多）。

### tokens

パスワードの代わりに Web ログインへ使えるログイントークン。モデル: `app/models/token.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| user_id | INTEGER | NO | - | 所有者（`users.id`、利用者削除時にカスケード削除） |
| identifier | TEXT | NO | - | 識別子（`[A-Za-z0-9_-]`、64 文字以内、一意） |
| name | TEXT | NO | - | 表示名 |
| token | TEXT | NO | - | トークン値（`mlc_` + 40 桁の 16 進、一意） |
| expires_at | DATETIME | YES | NULL | 有効期限（NULL は無期限） |
| created_at | DATETIME | NO | datetime('now') | 作成日時（UTC） |
| last_used_at | DATETIME | YES | NULL | 最終使用日時（UTC） |

リレーション: `user_id` → `users.id`（多対 1）。索引: `idx_tokens_user_id (user_id)`。

### settings

サーバー設定のうち、コードの既定値と異なる値のみを保存するキー / バリューストア。モデル: `app/models/setting.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| key | TEXT | NO | - | 設定キー（主キー）。`app/modules/constants.go` の `Setting*` 定数 |
| value | TEXT | NO | - | 設定値（文字列として保存） |

リレーション: なし

現在使用しているキー:

| key | 説明 | 既定値 |
| --- | --- | --- |
| web_listen | Web サーバーの待受アドレス | `0.0.0.0` |
| web_port | Web サーバーの待受ポート | `9790` |
| workers | 同時に実行するジョブ数（同時にアクセスするメールアカウント数の上限。1〜16） | `2` |
| check_times | メールチェック時刻（ローカル時刻 `HH:MM` のカンマ区切り） | `06:00,12:00,18:00` |
| agent_provider | 分析に使うエージェント CLI | `codex` |
| agent_enabled | チェック後に自動で分析を実行するか（`1` / `0`） | `1` |
| cookie_ttl_hours | Web セッションの有効時間（時間） | `720` |

### mailboxes

監視対象のメールアドレスと IMAP 接続設定。モデル: `app/models/mailbox.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| address | TEXT | NO | - | メールアドレス（小文字、一意）。原文ディレクトリ名と索引 DB 名の元になる |
| display_name | TEXT | NO | `''` | 表示名 |
| imap_host | TEXT | NO | - | IMAP サーバーのホスト名 |
| imap_port | INTEGER | NO | 993 | IMAP ポート |
| imap_security | TEXT | NO | `'ssl'` | 接続方式（`ssl` = IMAPS / `starttls` / `none`） |
| imap_username | TEXT | NO | - | IMAP ユーザー名 |
| imap_password_enc | TEXT | NO | - | IMAP パスワード（`data/mailcare.key` で AES-256-GCM 暗号化） |
| folder | TEXT | NO | `'INBOX'` | 監視するフォルダー |
| enabled | INTEGER | NO | 1 | 有効なら 1（無効なアドレスは自動チェックの対象外） |
| initial_days | INTEGER | NO | 90 | 初回チェックで遡る日数 |
| recent_days | INTEGER | NO | 30 | 2 回目以降のチェックで遡る日数 |
| last_checked_at | DATETIME | YES | NULL | 最終受信日時（UTC） |
| last_check_status | TEXT | NO | `''` | 最終受信の結果（`ok` / `error` / 空 = 未実行） |
| last_check_error | TEXT | NO | `''` | 最終受信のエラー内容 |
| last_uidvalidity | INTEGER | NO | 0 | 最後に見たフォルダーの UIDVALIDITY |
| created_at | DATETIME | NO | datetime('now') | 作成日時（UTC） |
| updated_at | DATETIME | NO | datetime('now') | 更新日時（UTC） |

リレーション: `jobs.mailbox_id` から参照される（1 対多）。索引 DB `data/mails/<address>.sqlite` と 1 対 1 に対応する。

### jobs

バックグラウンド処理（同期 / 受信 / 纏め / 解析 / 再索引 / 再判定）の投入と結果。モデル: `app/models/job.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| kind | TEXT | NO | - | 種別（`sync` / `fetch` / `group` / `analyze` / `reindex` / `reclassify`） |
| mailbox_id | INTEGER | YES | NULL | 対象メールアドレス（`mailboxes.id`。NULL は「全アドレスに展開する」ジョブ。削除時に NULL） |
| target | TEXT | NO | `''` | 追加の対象（`analyze` のグループキー、`*` = 対応対象の全グループ、空 = 解析待ちのグループ） |
| status | TEXT | NO | `'queued'` | 状態（`queued` / `running` / `done` / `error` / `canceled`） |
| progress | TEXT | NO | `''` | 進捗テキスト（実行中に随時更新） |
| result | TEXT | NO | `''` | 結果の要約 |
| error_message | TEXT | NO | `''` | エラー内容 |
| requested_by | TEXT | NO | `''` | 投入元（`scheduler` / `cli` / 利用者名） |
| created_at | DATETIME | NO | datetime('now') | 投入日時（UTC） |
| started_at | DATETIME | YES | NULL | 開始日時（UTC） |
| finished_at | DATETIME | YES | NULL | 終了日時（UTC） |

リレーション: `mailbox_id` → `mailboxes.id`（多対 1）。索引: `idx_jobs_status_created (status, created_at)`。

### goose_db_version（goose 管理）

goose がマイグレーションの適用状況を記録するために自動作成するテーブル。アプリケーションからは参照・更新しません。

## 2. 索引 DB（`data/mails/<address>.sqlite`）

スキーマ版: `PRAGMA user_version = 2`（`app/models/mailindex.go` の `MailIndexSchemaVersion`）。

### messages

取り込んだメール（バウンスかどうかに関わらず全件）。原文は同じディレクトリの `<message_key>.eml` / `.txt` / `.html` / `.json`。モデル: `app/models/message.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| message_key | TEXT | NO | - | メールキー（`YYYYMMDD-HHMMSS_<12桁hex>`、一意）。ファイル名の基底 |
| uid | INTEGER | NO | - | IMAP UID |
| uidvalidity | INTEGER | NO | - | 取得時のフォルダーの UIDVALIDITY |
| folder | TEXT | NO | `'INBOX'` | 取得元フォルダー |
| message_id | TEXT | NO | `''` | Message-ID ヘッダー |
| subject | TEXT | NO | `''` | 件名（MIME デコード済み） |
| from_address | TEXT | NO | `''` | 差出人アドレス |
| from_name | TEXT | NO | `''` | 差出人表示名 |
| to_address | TEXT | NO | `''` | 宛先アドレス（先頭） |
| date | DATETIME | YES | NULL | Date ヘッダー（UTC） |
| received_at | DATETIME | YES | NULL | IMAP INTERNALDATE（UTC） |
| size | INTEGER | NO | 0 | サイズ（バイト） |
| has_text | INTEGER | NO | 0 | テキスト本文があれば 1 |
| has_html | INTEGER | NO | 0 | HTML 本文があれば 1 |
| is_bounce | INTEGER | NO | 0 | 対象判定でバウンス（自動返信を含む）と判定されれば 1 |
| bounce_kind | TEXT | NO | `''` | 種別（`failed` / `delayed` / `auto_reply` / `other`、対象外は空） |
| classify_reason | TEXT | NO | `''` | 判定に一致したルール名 |
| group_key | TEXT | NO | `''` | 所属する纏めグループ（`groups.group_key`。対象外・自動返信は空） |
| classified | INTEGER | NO | 0 | 纏めフェーズで処理済みなら 1（受信直後は 0） |
| fetched_at | DATETIME | NO | - | 取り込み日時（UTC） |

制約: `UNIQUE(uidvalidity, uid, folder)`。索引: `idx_messages_date (date)`、`idx_messages_group (group_key)`、`idx_messages_bounce (is_bounce, date)`、`idx_messages_classified (classified)`。
リレーション: `group_key` → `groups.group_key`（多対 1、外部キー制約なし）。`bounces.message_id` から参照される（1 対 1）。

| original_recipient | TEXT | NO | `''` | 配信できなかった宛先アドレス |
| recipient_domain | TEXT | NO | `''` | 宛先ドメイン |
| action | TEXT | NO | `''` | DSN の Action（`failed` / `delayed` / `delivered` / `relayed` / `expanded`） |
| status_code | TEXT | NO | `''` | 拡張状態コード（例 `5.1.1`） |
| smtp_code | TEXT | NO | `''` | SMTP 応答コード（例 `550`） |
| diagnostic | TEXT | NO | `''` | 診断文（Diagnostic-Code または本文から抽出） |
| diagnostic_template | TEXT | NO | `''` | 診断テンプレート（揺れを除いた正規化文字列） |
| remote_mta | TEXT | NO | `''` | 相手側 MTA のホスト名 |
| remote_ip | TEXT | NO | `''` | 相手側 MTA の IP アドレス |

### groups

バウンスを対応基準単位で束ねた纏めグループ。モデル: `app/models/bounce_group.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| group_key | TEXT | NO | - | 主キー（`sha1(category|unit_value|authority)` の先頭 16 桁） |
| title | TEXT | NO | `''` | 表示タイトル（`<category>: <unit_value> @ <authority>`） |
| category | TEXT | NO | `''` | カテゴリ（`ip_blocked` / `rate_limited` / `auth_failure` / `sender_blocked` / `content_rejected` / `message_too_large` / `server_config` / `unknown_failure` / `user_unknown` / `mailbox_full` / `mailbox_disabled` / `domain_not_found` / `delivery_delay`） |
| unit_value | TEXT | NO | `''` | 対応単位（送信 IP、送信元アドレス、送信ドメイン、当方 MTA、宛先アドレス、宛先ドメイン） |
| authority | TEXT | NO | `''` | 判断主体（ブラックリスト提供元、宛先ドメイン、`unknown_failure` では状態コードと診断テンプレート） |
| actionable | INTEGER | NO | 1 | メールサーバー管理者が対応すべきなら 1。宛先側の問題は 0（アラートから除外、解析もしない） |
| bounce_kind | TEXT | NO | `''` | 種別（`failed` / `delayed` / `other`） |
| recipient_domain | TEXT | NO | `''` | 宛先ドメイン |
| status_code | TEXT | NO | `''` | 拡張状態コード |
| smtp_code | TEXT | NO | `''` | SMTP 応答コード |
| diagnostic_template | TEXT | NO | `''` | 診断テンプレート |
| responsible | TEXT | NO | `''` | 対応者区分（機械判定。分析報告の META で上書きされうる） |
| message_count | INTEGER | NO | 0 | 所属メール数 |
| recipient_count | INTEGER | NO | 0 | 宛先アドレスの種類数 |
| remote_ip_count | INTEGER | NO | 0 | 相手側 IP の種類数 |
| first_seen | DATETIME | YES | NULL | 最古のメール日時（UTC） |
| last_seen | DATETIME | YES | NULL | 最新のメール日時（UTC） |
| state | TEXT | NO | `'open'` | 対応状態（`open` / `resolved` / `ignored`） |
| state_updated_at | DATETIME | YES | NULL | 状態の変更日時（UTC） |
| needs_analysis | INTEGER | NO | 1 | 解析が必要（新規、または既存グループにメールが増えた）なら 1。解析完了で 0。対象外グループは解析しない |
| created_at | DATETIME | NO | - | 作成日時（UTC） |
| updated_at | DATETIME | NO | - | 更新日時（UTC） |

索引: `idx_groups_state (state, last_seen)`、`idx_groups_actionable (actionable, state)`。
リレーション: `messages.group_key` から参照される（1 対多）。`agent_reports.group_key` から参照される（1 対多）。

### agent_reports

エージェント CLI による分析報告（グループごとに履歴を保持し、最新の完了分を表示する）。モデル: `app/models/agent_report.go`。

| カラム名 | 型 | NULL | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| id | INTEGER | NO | AUTOINCREMENT | 主キー |
| group_key | TEXT | NO | - | 対象グループ（`groups.group_key`、グループ削除時にカスケード削除） |
| provider | TEXT | NO | - | 使用したプロバイダー（`codex` 等） |
| status | TEXT | NO | - | 状態（`running` / `completed` / `error`） |
| summary | TEXT | NO | `''` | 要約（META の summary、無ければ報告の冒頭） |
| responsible | TEXT | NO | `''` | エージェントが判断した対応者区分 |
| severity | TEXT | NO | `''` | 重大度（`high` / `medium` / `low`） |
| report_markdown | TEXT | NO | `''` | 報告本文（Markdown） |
| error_message | TEXT | NO | `''` | 失敗理由 |
| message_count | INTEGER | NO | 0 | 分析時点のグループのメール数 |
| started_at | DATETIME | YES | NULL | 開始日時（UTC） |
| finished_at | DATETIME | YES | NULL | 終了日時（UTC） |
| created_at | DATETIME | NO | - | 作成日時（UTC） |

索引: `idx_agent_reports_group (group_key, id)`。
リレーション: `group_key` → `groups.group_key`（多対 1）。
